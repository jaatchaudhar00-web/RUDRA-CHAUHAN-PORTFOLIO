RUDRA CHAUHAN — FUTURISTIC PORTFOLIO
=====================================

FILES
- index.html : website content and page sections
- style.css  : design, responsive layout, gradients and animations
- script.js  : mobile navigation, scroll reveals, reading progress
- README.txt : these instructions

PREVIEW ON YOUR LAPTOP
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview it in your browser.
4. For the best editing experience, open the folder in VS Code.

EDITING
- Change text and section headings in index.html.
- Change colors, spacing, and layout in style.css (look near the top for :root color variables).
- Change interactions in script.js.
- Save the file, then refresh the browser.
- Google Fonts need an internet connection; the rest of the page is local.

ACCURACY
This portfolio intentionally does not claim awards, certificates, work experience, completed projects, public contact details, or professional-level skills that were not supplied. The project area is clearly marked as a future update.

PUBLISHING
This ZIP is a website source package, not a live public URL. To publish it, upload the files to a static hosting service such as GitHub Pages or Netlify. Do not upload private contact details unless you want them public.
